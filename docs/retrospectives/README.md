# Retrospectives

Per-polecat retrospectives written at the end of work cycles. Each `RETROSPECTIVE-daydumb-<color>.md` captures what one polecat learned about the codebase, recurring pitfalls, and suggestions for future work in their area.

New retros follow the naming convention `RETROSPECTIVE-daydumb-<color>.md`, where `<color>` is the polecat name (e.g. `quartz`, `onyx`, `jade`).
